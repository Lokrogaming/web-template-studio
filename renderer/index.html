Deployment

  1. Per Workflow (empfohlen): Nutzen → Workflow → Repo wird erstellt, bei HTML wird Pages automatisch verknüpft.
  2. Manuell (.zip): Zip laden → entpacken → neues GitHub-Repo erstellen → pushen → Settings → Pages → Branch main / / (root).
  3. Node-Projekt: npm install, npm run build, dist/ deployen.
