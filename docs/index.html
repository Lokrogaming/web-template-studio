Templates-Repo

Website-Templates · Marketplace + Desktop-App

Website-Templates installieren – als .zip oder per Workflow.

Zwei Wege: 1. Template als .zip laden, entpacken & selbst deployen (für Erfahrene). 2. SiteSmith-App: browsen, auf Wunsch automatisch als GitHub-Repo anlegen, Pages verknüpfen & lokal previewen (empfohlen).

Download aktuell deaktiviert – die App wird gerade aufgesetzt. Templates gibt's schon im web-templates Repo (templates.json + /templates/*.zip, je mit .temp-config).

📦 .zip-Weg

Zip aus dem Template-Repo laden, entpacken, deployen. Anleitungen stehen im Detail-Panel der App.

✨ Workflow-Weg

SiteSmith prüft GitHub-Login & Node/npm, erstellt ein (umbenennbares) Repo inkl. README mit Deploy-Anleitung, verknüpft Pages bei HTML und startet eine localhost-Preview.

✅ Verifiziert

Templates mit "verified": true in templates.json tragen in der App ein Icon.

So geht's (kurz)

  1. SiteSmith öffnen → Template wählen → Install Template → „Willst du diese Vorlage nutzen?“
  2. Entweder .zip laden (Für Erfahrene) oder Per Workflow automatisieren (empfohlen).
  3. Bei Workflow: ggf. GitHub-Token anmelden, Repo-Namen anpassen, installieren, Preview starten.
